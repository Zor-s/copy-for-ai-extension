# Copy for AI

A VS Code extension that copies file paths and contents into your clipboard in an AI-friendly format.

Designed for quickly providing project context to AI assistants.

## Features

- Copy active file
- Copy selected files from Explorer
- Copy folders recursively
- Copy multiple files at once
- Skip binary files
- Sort files by path
- Include clear file boundaries
- Count tokens from copied content
